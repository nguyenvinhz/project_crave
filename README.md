# Project Crave

Skeleton for a JSP + Servlet + JPA + HikariCP food-ordering project using the
`QuanLyDatDoAn` MySQL database.

## Structure

- `backend/src/main/java`: Servlet controllers, DTOs, entities, services, repositories, config.
- `backend/src/main/resources`: JPA/HikariCP configuration placeholders.
- `frontend/src/main/webapp`: JSP views, `WEB-INF/web.xml`, and static assets.
- `database`: SQL script placeholders.
- `docs/api-skeleton.md`: API route outline.

The controller methods are stubs only. They define the intended API surface and
throw `UnsupportedOperationException` until real logic is added.
